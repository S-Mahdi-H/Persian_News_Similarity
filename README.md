# پروژه مقایسه میزان شباهت متون اخبار فارسی
### Persian News Similarity Analysis

## معرفی پروژه

این پروژه با هدف بررسی و اندازه‌گیری میزان شباهت محتوایی میان دو متن خبری فارسی طراحی و پیاده‌سازی شده است.

در این پروژه، ابتدا محتوای دو خبر از وب‌سایت‌های خبری استخراج می‌شود. سپس متن‌های استخراج‌شده با استفاده از روش‌های مختلف پیش‌پردازش زبان طبیعی (NLP) آماده‌سازی می‌شوند و در نهایت میزان شباهت آن‌ها با استفاده از معیارهای ریاضی محاسبه و مقایسه می‌شود.

هدف اصلی پروژه، بررسی عملکرد روش‌های مختلف سنجش شباهت متون و تحلیل نتایج حاصل از آن‌ها است.

## اهداف پروژه

- استخراج خودکار محتوای اخبار از صفحات وب
- آماده‌سازی و پاک‌سازی متون فارسی
- نرمال‌سازی حروف و ساختار متون
- حذف علائم نگارشی و واژه‌های ایستا
- ریشه‌یابی واژه‌ها
- تبدیل متون به بردارهای عددی
- محاسبه میزان شباهت دو متن با معیارهای مختلف
- مقایسه و تحلیل نتایج به‌دست‌آمده

## فناوری‌ها و ابزارهای استفاده‌شده

- **Python:** زبان برنامه‌نویسی اصلی پروژه
- **Playwright:** استخراج محتوای صفحات وب
- **BeautifulSoup:** پردازش محتوای HTML
- **Hazm:** پردازش و پیش‌پردازش زبان فارسی
- **NumPy:** انجام محاسبات عددی

## مراحل اجرای پروژه

### ۱. استخراج اخبار

در این مرحله، محتوای دو خبر از وب‌سایت‌های خبری استخراج می‌شود. برای این منظور از ابزار Playwright و کتابخانه BeautifulSoup استفاده شده است.

### ۲. پیش‌پردازش متون

به‌منظور آماده‌سازی متن‌ها، عملیات زیر انجام می‌شود:

- نرمال‌سازی متون فارسی
- حذف علائم نگارشی
- حذف واژه‌های ایستا (Stop Words)
- ریشه‌یابی واژه‌ها (Stemming)

### ۳. تبدیل متون به نمایش عددی

در این مرحله، متن‌های پردازش‌شده به بردارهای عددی تبدیل می‌شوند تا امکان انجام محاسبات ریاضی و مقایسه آن‌ها فراهم شود.

### ۴. محاسبه میزان شباهت

برای مقایسه دو متن از معیارهای زیر استفاده می‌شود:

- **Cosine Similarity:** اندازه‌گیری شباهت بر اساس زاویه بین دو بردار
- **Euclidean Distance:** اندازه‌گیری فاصله اقلیدسی بین دو بردار

### ۵. تحلیل نتایج

در مرحله پایانی، مقادیر به‌دست‌آمده از معیارهای مختلف بررسی و تفسیر می‌شوند تا میزان شباهت دو خبر مشخص شود.
